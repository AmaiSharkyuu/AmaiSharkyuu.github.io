AmaiCraft: Quick Reference Guide

Looking for specific Minecraft crafting recipes? AmaiCraft lists every craft in the game so you can build items quickly.

Every station is covered: crafting table, furnace, blast furnace, smoker, campfire, stonecutter, smithing table and brewing stand.

Our tool also includes basic Minecraft commands for admin items and cheats, a dedicated Jukebox section for music discs, all mob sounds from the game and a mining mini-game.
