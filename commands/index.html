        Questions
        
            
        
                How do I give myself a custom sword in Minecraft?
                
        Open the Custom item tab, pick a sword, type a name and choose its colors, add enchantments like Sharpness 255, then copy the command and paste it in the chat. You need cheats turned on or operator rights.
        
            
        
            
        
                Why does my /give command not work?
                
        Most of the time the command was made for another Minecraft version. Since 1.20.5 items use components in square brackets instead of NBT tags in curly brackets, and 1.21.5 changed how names are written again. Choose your exact version at the top of the generator and the command follows it.
        
            
        
            
        
                What is the highest enchantment level in Minecraft?
                
        With commands, enchantments go up to level 255 in every version since 1.17, far above the normal Sharpness V or Protection IV.
        
            
        
            
        
                How do I get a spawner of any mob?
                
        Open the Mob spawner tab, choose the mob and keep "A spawner that keeps making mobs" selected. You can change how many mobs it spawns, how often and how close a player has to be. Place it in Creative mode or as an operator.
        
            
        
            
        
                Does it work with Minecraft 1.12.2 and modpacks?
                
        Yes. Choose 1.12.2 in the version list: the generator writes the old syntax with numeric enchantment ids and § color codes. You can also type the id of a modded item, like create:wrench.
        
            
        
            
        
                Does it work on Bedrock Edition?
                
        No. The generator makes Java Edition commands. The Bedrock /give command cannot set names, lore or enchantments.
        
            
        
            
        
                How do I paste a command that is too long for the chat?
                
        The chat takes 256 characters. For longer commands, give yourself a command block with /give @p command_block, place it, paste the command inside and power it with a button.
