Useful Commands

Click on a command to copy it to your game.

🗿 Gamemodes

/gamemode creative Turn to Creative
/gamemode survival Turn to Survival
/gamemode adventure Turn to Adventure
/gamemode spectator Turn to Spectator

🛠️ Admin Items

/give @p command_block Give a command block
/give @p barrier Give an invisible block
/give @p light Give a light block
/give @p debug_stick Give a debug stick
/give @p structure_block Give a structure block
/give @p knowledge_book Give a knowledge book

🌍 Secret Mobs

/summon illusioner Summon an illusioner
/summon giant Summon a giant zombie

🌍 World & Time

/time set day Set the time to day
/gamerule keepInventory true Keep inventory after death

AmaiCraft: Quick Reference Guide

Looking for specific Minecraft crafting recipes? AmaiCraft lists every craft in the game so you can build items quickly.

It also includes basic Minecraft commands for admin items and cheats, a Jukebox for music discs, every hurt mob sound and a mining mini-game.
